### 🧭 为什么写代码 / Why I Code

> 曾经我被困在自己的世界里。后来发现，真正能帮助我理解世界、帮助别人的，不是药物，是亲手创造。在甘肃农村的粮仓里，我自学编程，用AI做工具。不是为了逃避，是为了让更多人——包括我自己——在困境中看到光。

> *I was once trapped in my own world. Then I discovered that what truly helps — myself and others — isn't medication, but creation. From a grain warehouse in rural China, I taught myself to code and build AI tools. Not to escape, but to bring light to those in the dark — myself included.*
